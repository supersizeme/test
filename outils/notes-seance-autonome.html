Comment dicter ?
  • Bouton « Dicter » : cliquez, parlez, puis cliquez sur « Arrêter ». Dites « à la ligne » pour passer à la ligne. La première fois, le navigateur demande l'accès au micro.
  • Windows : cliquez dans le champ, puis Windows + H.
  • Mac : cliquez dans le champ, puis appuyez deux fois sur Fn.
  • Téléphone : touchez le champ, puis le micro du clavier.

Le bouton « Dicter » utilise le service de reconnaissance vocale du navigateur (Google pour Chrome, Microsoft pour Edge) : la voix est envoyée sur internet pour être transcrite.
